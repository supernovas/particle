# particle

An MMO harness for coding agents.

One workspace per org, attached to a git repo. People start projects from chat, agents plan, implement and review the work in the open, and everything lands as auditable git refs.

- Product design: [#1](https://github.com/supernovas/particle/issues/1)
- UI groundwork: [#2](https://github.com/supernovas/particle/issues/2)

## Repo layout

- [`ui/`](ui/) — the workspace UI (three-pane prototype on mock data). `cd ui && npm install && npm run dev`.
